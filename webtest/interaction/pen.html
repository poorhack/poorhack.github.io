Before you start
  • Set the screen refresh rate to the highest value the device supports (90/120 Hz).
  • Turn off power saving mode and keep the battery at 50% or higher.
  • Update the browser. Save each browser under its own name, e.g. “Huawei MatePad 11.5 · Chrome” and “… · Huawei Browser”.
  • Turn off “Desktop site” mode.
  • Make sure the pen is charged and paired. On Huawei, note the connection type (NearLink or Bluetooth).
  • Close background apps. Have the same person run all tests in the same posture.
  • Record each step at least 3 times. The table shows the median of the runs.

End-to-end latency: video measurement

The browser can’t measure the real delay between the pen tip and the ink; the touch layer and the display itself add to it. Use slow-motion video to see the latency the user actually feels.

  1. Turn on “Video mode”; the pad fills the screen and the stroke gets thicker.
  2. Set a phone to slow motion (240 fps is ideal, 120 fps also works) and film the screen from above.
  3. Draw a straight line with the pen at a steady speed and stop abruptly.
  4. Step through the video frame by frame. Count the frames from when the pen tip stops until the ink catches up with it.
  5. Latency (ms) = frames × 1000 ÷ fps. At 240 fps one frame ≈ 4.2 ms.
  6. Measure at least 5 times on each device and enter each result below.
Data transfer

Copy all runs as JSON to move them to another browser or keep them with a report. To import, paste the JSON into the box.

What the measurements show
  • Pen sampling: recorded points ÷ drawing time. Coalesced points (getCoalescedEvents) are included; the signature’s biometric data is made of these points.
  • Digitizer rate: calculated from the median interval between consecutive points. Shows how often the pen and screen sample in hardware.
  • Points per event: a value near 1 means the browser delivers one point per display frame, so the hardware’s real rate isn’t reaching the page.
  • Event queue latency: the time between the OS creating an event and the page handling it. It isn’t end-to-end latency; it shows whether events wait in the browser.
  • Distinct pressure values in 400 samples: how many different pressure values appear in the same number of samples, for a fair comparison across devices. Most meaningful in the pressure ramp test.
  • Estimated pressure resolution: calculated from the smallest pressure step seen (1 ÷ step). A value below the pen’s spec suggests the browser rounds the data.
  • Low-latency drawing: opens the canvas in “desynchronized” mode. If latency drops visibly with it on, the signature app can use the same setting.
